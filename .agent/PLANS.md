# ExecPlan format

Use an ExecPlan for a significant feature, architectural foundation, or refactor. Keep it in `.agent/exec-plans/` and update its status and progress as work proceeds.

Each plan should include:

1. **Objective** — the user-visible result and scope boundaries.
2. **Context and decisions** — relevant project requirements and assumptions.
3. **Implementation steps** — ordered, concrete work that can be reviewed.
4. **Verification** — commands and manual checks, with limits stated honestly.
5. **Progress** — completed work, findings, and remaining items.

Plans are working documents. Do not use them to silently expand the requested scope.
